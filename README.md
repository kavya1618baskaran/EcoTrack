 🌱 EcoTrack – Smart Environmental Sustainability Tracker

 📌 About the Project

EcoTrack is a web-based environmental sustainability project developed to create awareness about protecting the environment and encouraging eco-friendly habits in everyday life.

The main purpose of EcoTrack is to help users understand the environmental impact of their daily activities and motivate them to make sustainable choices. It focuses on important environmental areas such as carbon footprint, water consumption, energy usage, and waste management.

The website provides a simple and user-friendly interface with user registration, login, and a dashboard through which users can navigate different environmental tracking sections.

🎯 Objectives

- To create awareness about environmental sustainability.
- To encourage users to save water and electricity.
- To promote waste reduction and proper waste management.
- To introduce carbon footprint tracking.
- To encourage eco-friendly habits in daily life.

 ✨ Features

- **Home Page:** Introduces EcoTrack and its purpose.
- **User Registration:** Allows new users to create an account.
- **User Login:** Allows registered users to log in.
- **Dashboard:** Provides navigation to different environmental sections.
- **Carbon Footprint:** Section planned for understanding carbon emissions.
- **Water Tracking:** Section planned for monitoring water usage.
- **Energy Tracking:** Section planned for monitoring electricity consumption.
- **Waste Management:** Section planned for encouraging waste reduction.
- **Eco Challenges:** Section planned for promoting sustainable activities.
- **Progress Reports:** Section planned for viewing environmental progress.

*Note: The tracking, challenge, and report sections are currently planned dashboard modules and are not yet fully implemented.*

🛠️ Technologies Used

- HTML – Structure of the website.
- CSS – Styling and page layout.
- JavaScript – User interactions and functionality.
- Local Storage – Stores registration information in the browser.
- Session Storage – Maintains the current login session.

 💻 Development Tools

- Visual Studio Code
- Google Chrome
- VS Code Live Server

 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the EcoTrack project folder in Visual Studio Code.
3. Locate the `index.html` file.
4. Right-click the file and select **Open with Live Server**.
5. The EcoTrack website will open in your browser.
